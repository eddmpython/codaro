# Design Foundation `_done` 자리표시자

구현, 지정 gate, 문서 갱신, packet 범위에 필요한 검토, completion evidence와 transition을 모두 통과한 packet만 이 경로로 이동한다. desktop/mobile 시각 검토는 해당 화면 packet이 소유하고 기계적인 token·package contract에 중복 요구하지 않는다.

이 README는 디렉터리 계약을 설명하는 문서이며 그 자체는 완료 증거가 아니다. 실제 완료 여부와 수는 각 packet의 completion evidence와 root transition ledger로만 판정한다.
